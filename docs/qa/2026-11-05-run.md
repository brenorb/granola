# QA run record — 2026-11-05

Full-inventory QA of the production build on a local, production-like stack
with sanitized production-scale data. Inventory and acceptance criteria:
[inventory.md](inventory.md). Findings: [bug-log.md](bug-log.md). Stack and
runner: [scripts/qa](../../scripts/qa/README.md).

## Settings

- Build: `npm run build` (Vite production bundle), served at
  `https://brenorb.com/granola/` with the shipped meta CSP unchanged.
- Browser: Playwright Chromium 1.63; production hostnames resolved to a local
  TLS proxy, every other hostname unresolvable, system proxy disabled.
- Mints: Nutshell 0.20.2 for `testnut.cashu.space` (`sat`, 100 ppk input fee)
  and cdk-mintd 0.18.3 for `testnut.cashudevkit.org` (`sat`, `usd`), both with
  fake Lightning that pays instantly. Distinct URLs and keysets; both
  advertise NUT-07, NUT-14 and NUT-17.
- Relays: khatru 0.19.1 with Badger storage for the three discovery relays;
  the inbox relay requires NIP-42 AUTH and limits kind 1059 reads to the
  authenticated recipient (both silent-filter and `CLOSED restricted:` modes
  tested). `ws://localhost:4870` is absent, as for most users.
- Data: 1,200 open orders (300 makers, created over 25 days), 400 canceled
  orders, 5 hostile events; best ask 49,500.00 and best bid 49,200.00 are the
  oldest orders. All keys are throwaway; the mint mnemonic is the public BIP39
  test vector.

## Method

1. Explored every control and workflow as a user (two to three independent
   browser contexts for maker/taker/racing taker, one context with two tabs,
   a 375 px phone context, a fast-forwarded clock for expiry).
2. Logged each defect with a reproduction and evidence; grouped them by cause.
3. Fixed by cause, adding a failing-first regression test per fix.
4. Ran `scripts/qa/inventory-run.mjs`, which replays the whole inventory, on
   the original build (`before`) and on the fixed build (`after`), each from
   the same seeded relay snapshot.
